# SaferStep

**From Warning Signs to the Right Action.**

SaferStep is a digital safety platform that helps people identify suspicious investment offers, practise scam scenarios, verify information through official sources, and understand what actions to take when something goes wrong.

## Key Features
- Investment scam awareness and warning signs.
- Interactive scam practice scenarios.
- Guided offer verification.
- Curated safety guidance and official reporting resources.
- AI-assisted guidance when API access is available, with a saved-guidance fallback.

## Technology
- React and TypeScript
- Tailwind CSS
- Vercel
- Lovable AI Gateway / OpenAI API integration

## Live Application
https://saferstep.vercel.app/

## Responsible Use
SaferStep provides educational safety guidance. It does not provide investment advice, certify investment platforms, or guarantee recovery of lost funds.
